# 签名与验签（通用）

根据不同第三方的签名机制，在各 provider 的 README 中给出“实现细节”。本文件只约束通用口径，确保实现一致。

## 通用约束

- 参与签名的字段必须明确：字段集合、排序规则、编码规则（UTF-8）、空值处理规则
- 必须明确签名输入的规范化方式：URL 编码、JSON 序列化（字段顺序/空格）、换行符
- 必须明确时间戳单位与容忍窗口（例如 5 分钟）
- 必须明确密钥轮换策略与版本标记方式（如果支持）

## 文档建议格式（每个 provider 都应提供）

```text
算法: HMAC-SHA256
消息构造:
  1) 按字段名 ASCII 升序排序
  2) 以 key=value&... 拼接
  3) message = <HTTP_METHOD>\n<PATH>\n<QUERY_OR_BODY>\n<TIMESTAMP>
编码: UTF-8
输出: hex lower
```
